# Коворкинг «Пространство»

Лендинг коворкинга, выполненный для лабораторной работы №3 по треку C: Sass + BEM.

## Почему этот инструмент

Sass удобен, когда на сайте много повторяющихся цветов, 
отступов и правил адаптивности, потому что их можно вынести в переменные и миксины.
В этом проекте он помогает один раз задать основные цвета, ширину контейнера
и точки перелома для мобильной, планшетной и компьютерной версий. Вложенность делает 
стили BEM-блока компактнее: например, элементы `navigation__link` и его состояние при
наведении находятся рядом. BEM удобен тем, что по имени класса сразу понятно, к какому
блоку относится элемент, поэтому стили проще поддерживать и изменять. При этом Sass может
мешать на очень маленьком сайте: перед показом страницы SCSS нужно отдельно скомпилировать
в обычный CSS. В отличие от трека с чистым CSS здесь есть переменные, миксины и вложенность,
а в отличие от CSS-фреймворков все стили написаны самостоятельно и не зависят от готовых компонентов.

## Файлы

- `index.html` — разметка лендинга с BEM-классами.
- `style.scss` — исходные стили Sass.
- `style.css` — скомпилированный CSS, подключённый к странице.

## Компиляция SCSS

```powershell
npx sass style.scss style.css --no-source-map
```
