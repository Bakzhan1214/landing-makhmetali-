# Coworking Landing Page

## Тема
Адаптивный лендинг для современного **коворкинга**.

## Ссылка
**GitHub Pages:** https://github.com/Bakzhan1214/landing-makhmetali-/tree/main

## Что сделано
* Создан лендинг на чистом **HTML5 + CSS3**.
* Использованы семантические теги: `header`, `nav`, `main`, `section`, `article`, `footer`, `form`.
* Добавлены основные блоки: Hero, информация о коворкинге, преимущества, тарифы, галерея и контакты.
* Добавлена форма с полями **имя, email и сообщение**.
* Для полей формы использованы `label` и `required`.
* Для изображений добавлен атрибут `alt`.
* Использована правильная структура заголовков `h1`, `h2`, `h3`.
* В `<head>` добавлены `title`, `meta description`, `viewport` и favicon.
* Реализована адаптивная верстка для экранов **375px и 1280px**.
* Использованы **Flexbox и CSS Grid**.
* JavaScript, Bootstrap, Tailwind и готовые шаблоны **не использовались**.

## Технологии
* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
